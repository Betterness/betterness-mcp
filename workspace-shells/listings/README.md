# Listings Shell

## Purpose

Defines how BetterClaw OS surfaces Smart Listings, providers, products, classes, routes, and nearby recommendations.

## Rules

- listings must feel contextual, not directory-like
- tie listings to the user's current goals or state
- use quiet source attribution from Betterness Graph or Betterness MCP

## BetterClaw OS Usage

Used by packages that connect recommendations to real-world actions.
