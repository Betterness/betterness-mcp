# Betterness Booking

Betterness Booking is the action layer that turns recommendations into real-world follow-through.

This area covers how Betterness-powered experiences can help users:

- discover classes, providers, and services
- choose the right option
- book or hand off to booking flows
- sync calendars and reminders
- follow up after appointments and classes

## Current Strategic Rails

- Mindbody = first-class booking rail
- Mariana Tek = first-class booking rail
- Wellhub = first-class or partner-grade booking/access rail
- ClassPass = guided handoff rail

## Why This Matters

Betterness should not stop at analysis.

It should help users:

- order labs
- find providers
- book classes
- plan schedules
- act on what their data suggests

This directory will hold the public integration and partner-facing booking docs over time.
