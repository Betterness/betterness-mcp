# Betterness CLI

Betterness CLI is the fast terminal and operator interface to the Betterness platform.

Use Betterness CLI when you want:

- lower-token local workflows
- scriptable automation
- cron-friendly health and operations flows
- a fast command surface for OpenClaw, Codex, Claude Code, and terminal-native users

## Relationship to MCP

- **Betterness MCP** is the universal remote integration surface
- **Betterness CLI** is the fast local and operator surface

They should share the same underlying capability layer.
