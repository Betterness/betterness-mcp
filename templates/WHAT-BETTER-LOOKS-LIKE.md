# What Better Looks Like

This is the canonical BetterClaw OS experience standard.

When creating or adapting a new package, use this file together with:

- `WORKSPACE.md`
- `PLANNING-MODE.md`
- `ANTI-PATTERNS.md`
- the BetterClaw design docs in `design/`

The goal is simple:

> Make the workspace feel like the Betterness app translated into an OpenClaw-native experience.

Core rules:

- one cohesive home, not many disconnected tabs
- action over observation
- context before token spend
- premium means calm, specific, and useful
- Betterness branding should be clear but quiet
- every package should help the user decide and act faster

For the full standard, use:

- `starters/betterclaw-os/WHAT-BETTER-LOOKS-LIKE.md`
