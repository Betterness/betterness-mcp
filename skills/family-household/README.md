# Family & Household

## Description
Skills that extend health optimization beyond the individual to the household unit. Couples Health Sync compares health data between two partners, identifies shared environmental deficiencies, quantifies how each partner's habits affect the other, and builds joint optimization plans. Health is more achievable when done as a shared project — this skill provides the framework and accountability structure.

## Skills

| Skill | Description |
|-------|-------------|
| `couples-health-sync` | Side-by-side health comparison for couples with joint optimization plan |

## Typical User Profile
- Both partners use Betterness MCP with at least one wearable each
- Couples where one or both partners are health-focused
- Households noticing shared health patterns (both tired, both getting sick)
- Partners with different health levels who want to support each other's goals
- Couples interested in shared longevity goals and coordinated lifestyle changes
