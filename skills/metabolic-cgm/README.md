# Metabolic Health & CGM

## Description
Skills focused on glucose control, insulin sensitivity, metabolic stress detection, and body composition clarity. Supports users with CGMs (Levels, Dexcom, Libre) as well as those relying on fasting glucose and HbA1c from standard blood panels. Provides frameworks for detecting insulin resistance early, understanding weight fluctuations, and separating true body composition progress from measurement noise.

## Skills

| Skill | Description |
|-------|-------------|
| `blood-sugar-optimizer` | Optimize glycemic responses using CGM, activity, sleep, and metabolic biomarkers |
| `pre-diabetes-monitor` | Detect insulin resistance and pre-diabetes years before standard diagnosis |
| `metabolic-health` | Insulin sensitivity and metabolic function assessment |
| `metabolic-stress-detector` | Detect early metabolic stress before visible performance decline |
| `weight-volatility-explainer` | Explain short-term weight fluctuations using multi-signal context |
| `body-comp-signal-separator` | Distinguish true body composition progress from measurement noise |

## Typical User Profile
- Wearing or has worn a continuous glucose monitor
- Has received a "borderline" fasting glucose or HbA1c result
- Struggling to understand why their weight fluctuates day to day
- Interested in metabolic health as a longevity strategy
- May have family history of type 2 diabetes or metabolic syndrome
- Wants to understand the connection between sleep, stress, and glucose regulation
