# Daily Health

## Description
Lightweight, high-frequency skills designed for daily and weekly health awareness. The morning briefing delivers a sub-100-word health snapshot each day. The weekly health report produces a structured trend analysis with tables and action items. These skills work with any wearable and require minimal configuration — ideal as the default entry point for new users.

## Skills

| Skill | Description |
|-------|-------------|
| `morning-briefing` | Daily 30-second health status briefing |
| `weekly-health-report` | Automated weekly health summary with trend analysis |

## Typical User Profile
- New to health tracking and wants a simple daily touchpoint
- Any wearable user who wants a structured weekly review
- Busy professionals who want health insights in under a minute
- Users who want to build health awareness habits before diving into deeper skills
- Works for all fitness levels — from casual walkers to serious athletes
