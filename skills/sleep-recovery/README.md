# Sleep & Recovery

## Description
Skills focused on analyzing and optimizing sleep architecture, HRV-driven recovery, stress resilience, and thermal interventions. These skills use wearable data to help users understand their recovery quality and make evidence-based decisions about training, lifestyle, and sleep environment.

## Skills

| Skill | Description |
|-------|-------------|
| `sleep-analyst` | Deep sleep architecture analysis with HRV correlation |
| `recovery-coach` | HRV-driven daily readiness and training guidance |
| `sleep-environment-tuner` | Tune sleep environment variables to improve restorative sleep |
| `thermal-recovery-orchestrator` | Correlate temperature interventions with sleep quality and readiness |
| `stress-resilience` | Autonomic nervous system balance and stress quantification |
| `jet-lag-recovery` | Jet lag recovery protocol using sleep stage and HRV adaptation tracking |

## Typical User Profile
- Uses a sleep tracker (Oura Ring, Whoop, Garmin, Eight Sleep, Apple Watch)
- Has at least 7 nights of sleep data
- Interested in optimizing recovery for athletic performance, longevity, or general wellbeing
- Wants objective data instead of guesswork about training readiness
- May struggle with inconsistent sleep, high stress, or frequent travel
