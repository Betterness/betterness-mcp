# Travel & Circadian

## Description
Skills for managing circadian rhythm disruption from travel and timezone changes. Covers both a detailed jet lag recovery protocol (day-by-day light, meal, exercise, and melatonin timing) and a general travel health advisor for ongoing re-entrainment tracking. These skills use real-time wearable data to measure adaptation progress and adjust the protocol daily.

## Skills

| Skill | Description |
|-------|-------------|
| `travel-health` | Jet lag mitigation and travel health optimization |
| `jet-lag-recovery` | Jet lag recovery protocol using sleep stage and HRV adaptation tracking (see sleep-recovery category) |

## Typical User Profile
- Travels internationally 2+ times per year
- Has experienced multi-day jet lag impacting performance or wellbeing
- Wears a sleep tracker (Oura, Garmin, Whoop, Apple Watch)
- Wants a protocol based on their actual adaptation data — not generic advice
- May be an executive, athlete, or frequent flyer who cannot afford multiple days of impaired function
