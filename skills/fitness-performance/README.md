# Fitness & Performance

## Description
Skills for athletes, fitness enthusiasts, and anyone training with intent. Covers training load management, endurance optimization, intensity distribution, post-workout recovery analysis, overtraining detection, and sport-specific analytics (Garmin, HIIT studios). Rooted in exercise science principles — acute:chronic workload ratio, polarized training, HRV-guided periodization.

## Skills

| Skill | Description |
|-------|-------------|
| `cardio-load-readiness-gate` | Daily green/yellow/red readiness gating for endurance load decisions |
| `endurance-optimizer` | Race preparation and endurance training analysis |
| `intensity-distribution-coach` | Optimize high/low intensity balance to improve adaptation and reduce burnout |
| `post-workout-recovery` | Track HRV rebound and recovery trajectory after intense training sessions |
| `athlete-overtraining-detector` | Detect overtraining syndrome using HRV, sleep, biomarkers, and training load |
| `garmin-performance` | Garmin-specific training load and performance analysis |
| `barrys-burn-balance` | Optimize high-intensity class frequency against recovery capacity |
| `body-recomp` | Data-driven body recomposition guidance |

## Typical User Profile
- Trains 3-6 days per week with structured workouts
- Uses a Garmin, Whoop, Oura, or Apple Watch to track training
- May be training for a race, event, or body composition goal
- Wants to train smarter — not just harder
- Has experienced plateaus, fatigue, or inconsistent performance
