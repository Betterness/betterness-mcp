# Device Guides

## Description
Skills that provide deep, device-specific analysis and interpretation. Currently focused on the Oura Ring — one of the most data-rich consumer health wearables — with skills that go beyond the app's built-in scores to surface custom readiness assessments, temperature-based illness detection, and activity-recovery balance analysis via the Betterness MCP.

## Skills

| Skill | Description |
|-------|-------------|
| `oura-deep-dive` | Oura Ring-specific readiness and recovery analysis |

## Typical User Profile
- Oura Ring user who wants more than the app's standard readiness and sleep scores
- Interested in custom readiness calculations using their own data
- Wants early illness detection from temperature and HRV trends
- Active person who needs to understand their training-recovery balance
- May also use other wearables but relies on Oura as the primary sleep and recovery tracker
