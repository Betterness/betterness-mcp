# Longevity

## Description
Skills built around evidence-based longevity medicine, inspired by the work of Peter Attia, David Sinclair, and current peer-reviewed research. Focuses on biological age measurement and reduction, the Four Horsemen risk framework (cardiovascular, cancer, neurodegeneration, metabolic disease), and prioritizing the highest-leverage lifestyle and biomarker interventions for healthspan extension.

## Skills

| Skill | Description |
|-------|-------------|
| `longevity-protocol` | Comprehensive longevity intervention protocol |
| `bio-age-reducer` | Personalized biological age reduction protocol |
| `biological-age-lever-ranker` | Rank the interventions most likely to improve biological age trajectory |

## Typical User Profile
- Oriented around lifespan and healthspan optimization
- Has completed or is interested in biological age testing
- Follows longevity thought leaders (Attia, Sinclair, Huberman)
- Wants data-driven prioritization — not generic wellness advice
- Typically combines wearables with comprehensive lab panels
- Sees health as an investment requiring regular measurement and iteration
