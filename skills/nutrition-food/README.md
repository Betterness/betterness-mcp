# Nutrition & Food

## Description
Skills that connect lab data to nutritional decisions. The supplement advisor generates evidence-based supplement recommendations grounded in actual biomarker deficiencies — never generic stacks. The gut health optimizer links inflammatory markers, nutrient absorption, sleep quality, and exercise load to digestive health and provides targeted gut restoration protocols.

## Skills

| Skill | Description |
|-------|-------------|
| `gut-health-optimizer` | Analyze gut-related biomarkers, inflammation, and lifestyle for digestive health |
| `supplement-advisor` | Lab-data-driven supplement recommendations |

## Typical User Profile
- Has recent blood panel results (CBC, vitamin D, iron, B12, hs-CRP)
- Dealing with unexplained bloating, food sensitivities, or low energy
- Wants supplement recommendations backed by their own data — not generic advice
- May be taking multiple supplements without knowing if they are effective
- Interested in the gut-brain and gut-immune connections
- Uses a wearable to correlate lifestyle with digestive health patterns
