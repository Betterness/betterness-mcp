# What Better Looks Like for Marathon

Marathon should feel like **a premium, phase-aware running workspace**.

Read the full standard in:

- `../WHAT-BETTER-LOOKS-LIKE.md`

Package-specific emphasis:

- one clear training-phase-aware home
- readiness should shape today's run, not just describe it
- race week should feel unmistakably different from base training
- plans should be specific, not motivational
- the user should feel coached, not monitored

If Marathon feels like a generic endurance tracker, it is failing the BetterClaw standard.
