# What Better Looks Like for Barry's / Studio

Barry's / Studio should feel like **a premium studio companion that wraps around class life**.

Read the full standard in:

- `../WHAT-BETTER-LOOKS-LIKE.md`

Package-specific emphasis:

- the workspace wraps around the class experience, not replaces it
- before-class and after-class value should be obvious
- readiness should influence intensity intelligently
- nutrition and recovery should feel practical, not preachy
- the experience should feel energizing, warm, and polished

If Barry's / Studio feels like a generic HIIT dashboard, it is failing the BetterClaw standard.
