# BetterClaw OS Starters

BetterClaw OS is a Betterness-powered health workspace system for OpenClaw.

This starter collection gives builders five flagship package directions:

- `recovery` — sleep, stress, and nervous system recovery
- `marathon` — race training, tapering, fueling, and recovery
- `biohacker-lab` — labs, supplements, protocols, and biological age
- `road-cycling` — watts, zones, routes, weather, and training load
- `barrys-studio` — the Barry's experience, shaped by recovery, cadence, and healthy decisions around class

## What Lives Here

- `recovery/` — the reference package and structural quality bar
- `marathon/` — flagship endurance package
- `biohacker-lab/` — flagship biomarker and protocol package
- `road-cycling/` — flagship power-based performance package
- `barrys-studio/` — flagship boutique studio package

## How to Use These Starters

1. Start with [START-HERE.md](./START-HERE.md).
2. Start with `recovery/` to understand the intended package structure.
3. Use the flagship package that best matches the user’s identity and goals.
4. Connect Betterness MCP with a valid API key.
5. Keep the workspace cohesive, calm, and action-oriented.
