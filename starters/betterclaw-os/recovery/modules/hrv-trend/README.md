# Module: HRV Trend

Tracks heart rate variability trajectory over 7-day and 30-day windows against personal baselines.

## When Active
Always shown in the workspace home view, below sleep architecture.

## Data Sources
- Betterness MCP: `getWearableData` (HRV)
- Betterness Graph: personal HRV baseline, trend direction, cross-domain correlations

## Output
Directional HRV trend with baseline reference and context on what is driving the trend.
