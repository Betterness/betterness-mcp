# Module: Sleep Architecture

Analyzes deep sleep, REM, light sleep, awakenings, and sleep efficiency against personal baselines.

## When Active
Always shown in the workspace home view, below the recovery verdict.

## Data Sources
- Betterness MCP: `getWearableData` (sleep stages)
- Betterness Graph: personal sleep stage baselines, trend data

## Output
Concise sleep stage summary with baseline comparison and one actionable insight.
