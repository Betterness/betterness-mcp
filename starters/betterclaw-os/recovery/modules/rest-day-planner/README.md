# Module: Rest Day Planner

Suggests restorative activities when recovery is amber or red.

## When Active
Shown on amber/red recovery days.

## Data Sources
- Recovery verdict
- Betterness MCP: `searchPartners` (recovery studios, yoga, float, massage)
- Betterness Graph: user preferences, past recovery activity effectiveness
- Local memory: preferred rest day activities

## Output
2-3 specific restorative activity suggestions, optionally with nearby provider options.
