# What Better Looks Like for Recovery

Recovery should feel like **the Betterness app for nervous system decisions**.

Read the full standard in:

- `../WHAT-BETTER-LOOKS-LIKE.md`

Package-specific emphasis:

- one clear morning verdict
- calm, non-alarmist language
- action over metrics
- trend awareness without dashboard sprawl
- sleep and HRV should feel interpreted, not merely displayed

If Recovery feels like a metric wall or a generic wearable report, it is failing the BetterClaw standard.
