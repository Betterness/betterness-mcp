# What Better Looks Like for Road Cycling

Road Cycling should feel like **a power-aware coaching workspace**.

Read the full standard in:

- `../WHAT-BETTER-LOOKS-LIKE.md`

Package-specific emphasis:

- think in watts, zones, elevation, weather, and route choice
- the home should make ride decisions easier immediately
- specificity beats hype every time
- the bike itself is part of the system
- route and readiness should feel connected, not separate

If Road Cycling feels like a generic cardio dashboard, it is failing the BetterClaw standard.
