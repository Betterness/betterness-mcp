# Module: Supplement Stack

Full inventory of the user's supplement stack with dosing, timing, quality validation, and biomarker correlation.

## When Active
Shown when supplements are logged, or when the user asks about their stack.

## Data Sources
- Local memory: supplement inventory (name, brand, dose, form, timing)
- Betterness Graph: biomarker correlation for each supplement
- Browser: brand research and third-party testing validation (when requested)

## Output
Stack inventory with: supplement name, brand, dose, form, timing, target biomarker, current biomarker status, and quality assessment.

## Quality Assessment Includes
- Third-party testing (NSF, USP, ConsumerLab, BSCG, Informed Sport)
- Brand reputation and manufacturing standards (GMP, cGMP)
- Form bioavailability (e.g., magnesium glycinate vs oxide)
- Cofactor completeness (e.g., vitamin D with K2, iron with vitamin C)
- Monthly cost
