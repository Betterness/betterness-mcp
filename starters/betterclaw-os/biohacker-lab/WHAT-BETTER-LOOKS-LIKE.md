# What Better Looks Like for Biohacker Lab

Biohacker Lab should feel like **a private biomarker operating system**.

Read the full standard in:

- `../WHAT-BETTER-LOOKS-LIKE.md`

Package-specific emphasis:

- lead with what changed and what matters
- labs should feel longitudinal, not static
- protocol tracking should feel organized, not obsessive
- every review should suggest a next decision
- depth should feel precise and premium, not academic and bloated

If Biohacker Lab feels like a spreadsheet with opinions, it is failing the BetterClaw standard.
